# MOTION 動きで覚える英単語

英単語・句動詞・イディオム・TOEIC語彙を、モーション（3D／場面イラスト）と音声で、意味ごとつかむ学習アプリ。
スマホのブラウザで開き、ホーム画面に追加するとアプリとして使える（Android / iPhone）。

公開ページ：https://m0a2t0u7.github.io/motion-words/

## できること

- 1項目ごとに、英語・発音記号・英語音声・この場面での意味・日本語訳・例文と訳・コアイメージ・ほかの意味・専用モーション
- 連続再生：順に進む／1語をくり返す、順番／ランダム、範囲（カテゴリ・マイリスト）、くり返し回数、速度、間隔、読み上げる内容
- 基本の読み上げ順：英語の表現 → 英語の例文 → 日本語の意味（例文の日本語訳も追加できる）
- 一覧と検索、マイリスト（☆）、モーションを見て表現を選ぶ確認問題
- 設定とマイリストは端末に保存。一度開いたページはオフラインでも開ける

## 再生の範囲について

- 画面を開いたまま：設定どおりに続けて再生する。「再生中は画面を消さない」をオンにすると画面が自動で消えない（対応ブラウザのみ）。
- 別アプリ使用中・画面ロック中：再生を止める。ブラウザの読み上げ機能は、裏に回ったときの動きが端末ごとに違い、音声がずれたり残ったりするため。

## 収録数の数え方

`node tools/build-index.mjs` がデータを検証して `data/index.json` を作り、その実数だけを画面に出す。

- 収録：項目の総数
- 単語：空白を含まない項目（push, postpone など）
- 表現：句動詞・イディオムなど空白を含む項目
- モーション付き／3D：シーンファイルがある項目／そのうち3D

## 項目の追加手順

1. `data/items/<カテゴリ>.json` に項目を足す（`phrasal` / `daily` / `idiom` / `toeic`）。
   必須：`id`, `en`, `ipa`, `sense`（この場面の意味）, `ja`, `ex`（`en`, `ja`, `mark`）, `core`。任意：`diff`（似た表現との違い）, `other`（ほかの意味）, `motion`（`"2d"` / `"3d"`）。
2. `motion` を付けたら `js/scenes/<id>.js` を作る。作り方は `docs/SCENES.md`。
3. `node tools/build-index.mjs` を実行（エラーが出たら直す）。
4. 確認：`python3 -m http.server 8765` を起動し、`tools/snap.py`（コマ送り画像）と `tools/apptest.py`（全体の動作）で見る。
5. `sw.js` の `VERSION` を上げてから公開する（古いキャッシュを消すため）。

## 構成

```
index.html / css/app.css     画面
js/app.js                    画面の操作
js/player.js                 連続再生（止める・切り替えるときに前の読み上げを必ず破棄）
js/speech.js                 読み上げ
js/stage.js                  モーション表示（シーンは必要になったときだけ読み込む）
js/kit2d.js / js/kit3d.js    2D・3Dシーンの共通部品
js/scenes/<id>.js            項目ごとのモーション
data/index.json              一覧（自動生成）
data/items/*.json            教材データ
vendor/three.js              3D描画ライブラリ（three.js、MITライセンス）
```

キャラクター「まめ」と全シーンはこのアプリのための独自制作。
