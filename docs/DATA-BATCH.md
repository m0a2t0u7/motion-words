# 教材データの作り方（候補CSVから1バッチ100件）

入力：`data/staging/inA-XX.json`（CSV の行。english / category / meaning_ja / visual_hint / ID）
出力：`data/staging/outA-XX.json`（下の形の配列。入力と同じ順・同じ件数）

```json
{
  "src": "M0001",
  "id": "wake-up",
  "cat": "phrasal",
  "en": "wake up",
  "ipa": "/ˌweɪk ˈʌp/",
  "sense": "（眠りから）目を覚ます",
  "ja": "目を覚ます",
  "ex": { "en": "I woke up at six this morning.", "ja": "今朝は6時に目が覚めた。", "mark": ["woke up"] },
  "core": "眠っている状態から、意識が上（up）がってくる。",
  "diff": "get up は起き上がること。wake up は目が覚めること。",
  "other": ["（人を）起こす：wake someone up"]
}
```

## 決まり

- `cat`：句動詞・複合動詞 → `phrasal`、イディオム・慣用表現 → `idiom`、単語 → `word`
- `id`：英語を小文字にし、空白・記号をハイフンに（例 `a-piece-of-cake`、`don't` → `dont`）。
- `ipa`：アメリカ英語、スラッシュで囲む。句動詞は強勢記号を付ける。
- `sense`：CSV の meaning_ja を土台に、扱う意味を1つに絞り、必要ならかっこで対象・場面を補う。多義語は visual_hint の場面の意味を選ぶ。
- `ja`：短い訳（画面に大きく出る）。sense と同じでもよい。
- `ex.en`：その意味で使う、自然で短い例文（12語以内が目安）。中学〜高校レベルの文法。固有名詞・ブランド名を使わない。
- `ex.ja`：自然な日本語訳（直訳しない）。
- `ex.mark`：例文中で見出し語に当たる部分（活用形のまま、例文にそのまま含まれる文字列）。分かれている句動詞は2つに分ける（`["took", "out"]`）。
- `core`：意味の中心となる感覚を1〜2文。根拠のない語源は書かない。
- `diff`：まぎらわしい語がはっきりあるときだけ、1文で違いを書く。なければ省く。
- `other`：よく使う別の意味を0〜2個。「（対象）訳：例」の形。
- 「絶対に忘れない」などの効果は書かない。差別的・性的・暴力的な例文にしない。
- 不確かな意味・用法は使わない（自信のない多義は sense から外す）。
