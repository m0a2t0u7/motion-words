## 仕組み
- 素のES modules のPWA。`js/scenes/<id>.js` が専用モーション（meta と create(k)、update(t) は t だけで決まる純関数）
- `js/tpl.js` が型モーション（データの tpl:{t,...}）
- データは `data/items/{phrasal,idiom,phrase,word,daily,toeic}.json`。`node tools/build-index.mjs` で検証して `data/index.json` を作る
  - 注意：2026-10-23 に Node.js の版チェックが入った。22.23.4 / 24.22.1 / 26.12.1 以上が必要
- シーンを作ったら、データ側で `"motion":"2d"` を付けて build-index を実行する
- `sw.js` の VERSION を上げてからコミット＆push すると、端末にも反映される
- 確認ツール
  - `tools/preview.html?id=<id>&kind=2d&t=<秒>`
  - `tools/snap.py`（コマ送り画像）
  - `tools/apptest.py`（全体テスト。合言葉はテスト側で回避済み）
- ルールは `docs/SCENES.md`。どの場面にも緑のキャラ（まめ）が出て動く。絵文字の人物は使わない。手に持つ物を浮かせない。例文と食い違えない。子ども向けに不適切な内容（死・喫煙・流血）は作らない
